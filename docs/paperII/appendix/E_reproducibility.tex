\subsection{Code, results and provenance}

All results come from one Python package and its scripts, shared with
Paper~I. Every run writes a JSON file with its configuration, seeds,
per-cycle values and wall time; every table body and figure in this paper
is produced by a script in \texttt{scripts/paper\_figures/} that reads only
these result files and writes a sidecar file listing its inputs, the commit
and a time stamp. A decision log records every choice of model, setting and
convention and every correction made while writing, and a
number-provenance check compares every decimal number in the text with the
generated tables and the result files.
% TODO(G8): tagged release commit and archive DOI.

The experiments are run by \texttt{scripts/exp\_h9\_tiled\_da.py} (the latent
filter with shifted tilings, forecasts and the robustness options),
\texttt{scripts/exp\_i11\_pde\_letkf.py} (the physics-based filter with wrong
models, parameter estimation, bias correction and the hidden-field truth),
\texttt{scripts/exp\_i24\_phys\_emulator.py} (the learned model inside a
physical-space filter), \texttt{scripts/exp\_j16\_estimate\_pde\_model\_error.py}
(offline one-cycle residuals), \texttt{scripts/exp\_j17h\_fit.py} (best fits of
the wrong-damping models) and \texttt{scripts/exp\_j18b\_roundtrip.py} (the
round-trip test). The noisy-data model is trained by
\texttt{scripts/train\_kolmogorov\_crop.py --data-noise 0.1}. The library
modules are \texttt{ks\_latent/da/letkf\_local.py} (per-site filter with
RTPS), \texttt{letkf\_phys.py} (physical-space filter, multi-field states),
\texttt{param\_est.py} (parameter estimation), \texttt{model\_error.py}, and in
\texttt{ks\_latent/solver/} the wrong-model operators of \texttt{ks2d.py}, the
cached imperfect-model truths of \texttt{twin.py} and the hidden-field system
of \texttt{ks2d\_memory.py}. The queues that ran every experiment are kept as
\texttt{scripts/run\_*.sh}; the missing-process cases are run by \texttt{scripts/run\_j17g*.sh}, and the
reruns with the parameter-spread floor by \texttt{scripts/run\_r7.py} and \texttt{scripts/run\_r7b.py}.

\subsection{Numerics, seeds and tests}

The PDEs are integrated in double precision on the CPU with ETDRK4. The
networks are trained in single precision on the GPU of an Apple M5 Pro
(48~GB unified memory), which is not bitwise reproducible; all filter
linear algebra is done in double precision on the CPU. Filter seeds change
the initial ensemble, the observation noise and the model noise; seeds 1
and 2 also change the truth's initial state. The software environment is
Python 3.11.15, PyTorch 2.13.0, NumPy 1.26.4 and SciPy 1.17.1, fixed by an
exported environment file.

Unit tests check the properties the paper relies on: the decoder
Jacobian is exactly block-diagonal at zero reach
(Proposition~\ref{prop:blockdiag}); the coloured construction equals
reverse-mode differentiation exactly, and the observation-to-site map is
checked pixel by pixel; deployment grids keep the training spacing; with
a linear observation operator and Gaussian prior, the particle flow
filter, the dense and per-site ensemble Kalman filters and the serial
filter converge to the Kalman posterior at large ensemble size; the
deterministic per-site transform reproduces the Kalman update with the
ensemble covariance exactly; sites beyond the taper support are left
unchanged; the projected and serial forms of sampling error correction
reduce to the plain filter for an identity correction; the hidden-field
solver matches the exact solution of its linearization; and the joint
parameter update equals the ensemble Kalman regression.

\subsection{Compute}

All runs used one workstation. A data assimilation run of 100 cycles takes
$9$--$97$~s of wall time up to $88^2$ and $4$--$59$~min at $220^2$--$440^2$, with one or four
tilings (Table~\ref{tab:da_cost}); a model spectrum at $66^2$, about 5~min; a
2D KS truth at $66^2$, about 1.5~h; training the 12-channel model, about 7~h, almost all of it the propagator, on a workstation shared with other runs.
